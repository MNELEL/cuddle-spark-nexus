## מדריך שימוש — הכיתה שלי

כתובת המערכת: **hakitasheli.lovable.app**
מדריך זה נכתב לפי המצב הפעיל במערכת נכון ל-14 באוגוסט 2026.

---

### איך המערכת בנויה

כל דבר מתחיל ברשימת **הכיתות שלי** (`/classes`). משם נכנסים לכל כיתה ספציפית, ובתוך דף הכיתה נמצאים רוב הכלים היומיומיים. בנוסף יש שלושה אזורים כלליים שלא תלויים בכיתה מסוימת: **ארגז הכלים** (`/toolkit`), **הגדרות** (`/settings`), ו**מפת המערכת** (`/map`) שמרכזת הכול במקום אחד עם הסבר קצר לכל פריט וחיפוש.

אם בשלב כלשהו אינך זוכר איפה משהו נמצא — הכי מהיר להיכנס ל-`/map`, לחפש את שם הפעולה, וללחוץ עליה.

---

### 1. ניהול כיתה יום-יום

כל הפריטים הבאים נמצאים בתוך דף כיתה ספציפית (נכנסים אליו דרך `/classes`).

| פיצ'ר | למה נועד |
|---|---|
| רשימת תלמידים, נוכחות והתנהגות | המסך הראשי של הכיתה — סימון נוכחות יומית, מעקב נקודות התנהגות, ופתיחת תיק לכל תלמיד. |
| מערכת שעות ותורנויות | לוח שבועי מלא עם לוח עברי, חגים, וחלוקת תורנויות אוטומטית לתלמידים. |
| סידור הושבה ותצוגת כיתה | קביעת מקום ישיבה לכל תלמיד וצפייה בכיתה בתלת-ממד, עם אשף לסידור אוטומטי. |
| סיכום יומי | מסמך "מה קרה היום" מוכן להדפסה או לשליחה להורים. |
| עלון שבועי לכיתה (`/bulletins`) | עלון עם סיכום השבוע, חידה ופעילויות לתלמידים. יש תצוגה מקדימה לפני פרסום, היסטוריית גרסאות קודמות, ואפשרות ייצוא הטקסט גם לתעודות. |
| דף קשר שבועי להורים (`/weekly-sheet`) | תבנית "דף קשר" — הספק חומר לפי מקצועות, מבחנים והודעות, ודף חתימת הורים להדפסה. שונה מהעלון השבועי — זו טפסולוגיה מודפסת. |
| לוח אירועים | מבחנים, ימי הולדת (כולל עברי) ואירועי כיתה במקום אחד. |

### 5. חומרי הוראה וכלי שיעור

ספריית חומרי הוראה (`/resources`):

| יכולת | הסבר |
|---|---|

| עורך סיווג ותגיות | תיקון ידני עם שמירת היסטוריית גרסאות. |
| עורך טקסט OCR | רמת ודאות, תיקון ידני, סריקה מחדש. |
| חומרים דומים | מוצא חומרים דומים לפי דמיון תוכן. |
| הורדה מרוכזת ל-ZIP | בחירה מרובה והורדה כקובץ אחד. |
| שמירת הקובץ המקורי | הטקסט וגם הקובץ המקורי נשמרים ונגישים. |
| מועדפים ורמת קושי | סימון וסינון. |

כלים נוספים:

| פיצ'ר | למה נועד |
|---|---|

| מאגר שאלות (`/questions`) | בנק שאלות לפי מקצוע ונושא. |
| ארגז כלים לשיעור (`/toolkit`) | טיימר, בוחר אקראי, מדד רעש וכרטיסיות. |
| לוח צלצולים ופעמונים | תזמון צלצולים והפסקות. |
| ניהול צלילים ואפקטים | ספריית צלילים, כולל העלאה עצמית. |

### 6. תלמידים, ייבוא ומעבר שנה

| פיצ'ר | למה נועד |
|---|---|
| העלאה חכמה של רשימת תלמידים (`/ingest`) | זיהוי אוטומטי משדות עבריים, מיזוג שלא מוחק מידע קיים. |

| דוח מסירה בין מלמדים | PDF חסוי עם מידע רגיש והנחיות, כולל תאריך עדכון אחרון. |

הגנת ארכיון: כיתה בארכיון נעולה לעריכה, עם "החזר לפעילות" בלחיצה אחת.

### 7. הגדרות ואבטחה — `/settings`

| לשונית | תוכן |
|---|---|
| כללי | מצב מנוי/ניסיון ובחירת ערכת נושא. |
| אבטחה | קוד PIN לנעילת מכשיר משותף. |
| תזכורות | העדפות תזכורות ומיילים. |
| מסמכים | תבניות מסמכים. |
| מיתוג (`/settings/brand`) | לוגו ושם שמוטמעים בכל מסמך. |
| ערכת נושא (`/settings/theme`) | מראה כללי, נשמר לכל המכשירים. |

נוספים: דף קשר של המוסד (`/contact-sheet`) ומדריך חכם (`/onboarding`) — שישה שלבים מהקמה ראשונה ועד דוח ראשון להורים.
